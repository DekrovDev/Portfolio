Dekrov QR

A privacy-friendly QR code generator that creates practical codes locally in the browser.

Completed successfully HTML + CSS + JavaScript Local processing PNG + SVG

Available now

Try it or inspect the code

Dekrov QR works entirely in the browser: entered data is encoded locally and never needs a server or account.

Open demo View on GitHub

Result

Dekrov QR is a compact utility with a polished product flow: it turns several common QR scenarios into one fast, private tool that works on desktop and mobile without registration.

Problem

Creating a QR code should be quick, understandable, and private. Many generators add friction with accounts, ads, or remote data handling for a simple task.

Solution

A focused browser tool with clear input flows, validation, live preview, customization, and PNG or SVG export — without a backend.

6 formats Links, text, Wi-Fi, phone numbers, email, and vCard contacts.
Browser-only QR generation happens locally; entered content is not sent to a server.
Two exports Download a ready-to-use code as PNG or a scalable SVG.

Features

Smart input flows

Each QR type exposes only the relevant fields, including Wi-Fi security options and contact data.

Scan-safe customization

Color contrast is checked before export, while transparent backgrounds receive a clear warning.

Practical exports

Adjustable resolution and direct PNG/SVG downloads make the result usable on screen and in print.

How it works

01

Choose the content type

Select a link, plain text, Wi-Fi network, phone number, email, or contact card. The form adapts to the selected format.

02

Validate and customize

The tool validates the entered values, builds the correct QR payload, and checks whether the chosen colors remain easy to scan.

03

Preview and export

Review the generated code immediately, adjust its resolution, then download a raster PNG or scalable SVG file.

Input quality

Links, phone numbers, email addresses, Wi-Fi credentials, and contact fields have format-specific checks. Invalid or incomplete data is explained before export.

Privacy by design

There is no registration, database, analytics payload, or server-side generation step. The content stays inside the current browser session.

Technology Stack

HTML Semantic structure and accessible form controls. CSS Responsive interface, custom controls, and visual states. JavaScript Validation, QR payload creation, previews, clipboard, and downloads. qrcode-generator Client-side QR encoding library used to generate the code matrix.
